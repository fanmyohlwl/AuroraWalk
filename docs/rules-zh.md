# 不用投影片的口头说明

## 大约一分钟

我的作品叫「雪林漫步」。我想让观众像在北欧的夜晚散步一样，放慢一点，不需要完成任何任务。

它的复杂画面是从几条简单规则长出来的。首先，天空里有许多小光点，每个光点只和左右的邻居交换亮度和运动。少量能量会随机进入某一个地方，再扩散出去；运动同时会慢慢减弱。很多小变化连在一起，就形成整片流动的极光褶皱，而不是播放事先做好的视频。

第二，树和动物都有一个离我们多远的位置。我们不断向前走，近处的东西看起来更大、移得更快，远处的东西更小、移得更慢。树退到身后以后，会在前方重新生成，所以有限的对象可以组成一直走不完的森林。

第三，动物只注意附近的同类：稍微跟随它们的方向，但又不会挤在一起；它们也会尽量留在森林空地周围。我们挥手，会随机让树上的雪落下来，或者召来小动物。雪花被轻微的风推动，极光也受同一阵风影响。

所以我不能提前指定每一秒会长什么样，但能用这些简单规则创造一个稳定、不断变化、让人放松的小世界。

## 被追问时可以解释

- **什么算涌现？** 没有哪一条规则直接规定「这里必须出现完整的极光波浪」。光点之间的局部作用叠加，形成更大的褶皱和亮度纹路。动物的相互跟随和避让，也会产生小群体的变化。
- **哪些是美术设计，而不是涌现？** 树和动物的像素外形、天空配色、森林空地的布局是我设计的。随机刷新本身也不等于涌现。我把涌现主要放在光点的相互影响和动物的局部行为上。
- **为什么不会越来越乱？** 光的运动有阻力，能量会衰减，动物数量有上限，树使用循环池，落雪到地面后会被清除。规则既推动变化，也限制变化。
- **交互有什么作用？** 观众可以改变颜色、轻微影响风，挥手加入一个小扰动。世界继续按自己的规则变化，观众不是在操纵一个必须赢的游戏。
- **为什么使用 ml5？** 它把摄像头画面转换成手部关键点。只要手掌稳定出现一小会儿，或小幅移动，就会触发事件，并加上两秒冷却时间。静止手掌不会不断触发。按 D 可以查看关键点和置信度。不打开摄像头也能用按钮体验。
